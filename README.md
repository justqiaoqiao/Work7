# Taichi 质点-弹簧布料物理模拟实验
## 项目简介
基于 Taichi GPU 并行框架实现质点-弹簧布料物理模拟，实现显式、半隐式、隐式欧拉三种数值积分求解器，搭配 GGUI 交互面板实时切换算法、重置场景，对比不同积分方案的模拟稳定性。

## 实验目标
1. 掌握 Taichi 3D 动态场景渲染，使用 GGUI 搭建交互控制面板
2. 理解质点-弹簧物理模型，实现弹力、阻尼力计算，通过速度钳制处理数值爆炸
3. 独立编写三种数值积分求解器，对比物理模拟稳定性差异
4. 掌握 `ti.kernel` / `ti.func` 编写 GPU 并行代码，理解状态同步与 Kernel 性能优化

## 实验原理
### 1. 质点-弹簧模型
布料离散为网格质点集合，质点间通过结构弹簧连接，基于胡克定律计算弹力，引入阻尼力防止系统能量发散。
弹簧弹力：
$$f_{a} = -k_{s} (|x_a - x_b| - l) \frac{x_a - x_b}{|x_a - x_b|}$$
阻尼力：
$$f_{d} = -k_{d} v_{a}$$

### 2. 数值积分方法
依据牛顿第二定律 $a=F/m$，时间步长 $\Delta t$ 内更新质点速度与位置：
- **显式欧拉**
$$
\begin{cases}
x_{t+1} = x_{t} + v_{t} \Delta t \\
v_{t+1} = v_{t} + a_{t} \Delta t
\end{cases}
$$
- **半隐式欧拉**
$$
\begin{cases}
v_{t+1} = v_{t} + a_{t} \Delta t \\
x_{t+1} = x_{t} + v_{t+1} \Delta t
\end{cases}
$$
- **隐式欧拉（定点迭代近似求解）**
$$
\begin{cases}
v_{t+1} = v_{t} + a_{t+1} \Delta t \\
x_{t+1} = x_{t} + v_{t+1} \Delta t
\end{cases}
$$

## 实验任务与步骤
### 任务1 场景初始化
- 自定义布料网格尺寸，初始化质点位置、速度、受力与弹簧拓扑结构
- 拆分多个 `@ti.kernel` 分步初始化，保证 GPU 多线程状态同步

### 任务2 力学计算与数值防爆
- `compute_forces_on()`：计算重力、阻尼力、弹簧力，使用 `ti.atomic_add` 规避多线程写入冲突
- `clamp_velocity()`：限制质点最大速度，抑制数值爆炸
- 力学函数封装为 `@ti.func`，编译内联减少 GPU 函数调用开销

### 任务3 积分求解器（核心）
实现三个独立计算 Kernel：
- `step_explicit()`：显式欧拉求解
- `step_semi_implicit()`：半隐式欧拉求解
- `step_implicit_iter()`：隐式欧拉定点迭代求解
优化方案：受力计算与状态更新合并至同一 Kernel，减少 Kernel 启动次数

### 任务4 渲染与 GGUI 交互
- 使用 `ti.ui.Window` 构建 3D 布料渲染场景
- GGUI 控制面板功能：切换积分算法、暂停模拟、一键重置布料
